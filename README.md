# Reinforcement Learning: Q-Learning using FrozenLake

## About

This repository contains a learner-oriented Jupyter Notebook for understanding and implementing the **Q-Learning algorithm**, a model-free reinforcement learning algorithm.

The notebook uses the **FrozenLake-v1 environment from Gymnasium** to demonstrate how an agent learns to select actions through interaction with an environment and gradually improves its decision-making using rewards.

The notebook is designed for students to understand the concepts of reinforcement learning through explanation, code implementation, visualization, and hands-on activities.
